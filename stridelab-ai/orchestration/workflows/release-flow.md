# Release Flow

1. Freeze candidate scope.
2. Gather implementation and verification evidence.
3. Confirm G3 security/privacy/compliance PASS.
4. Confirm G5 quality/performance/reliability PASS.
5. Verify migrations, backups, rollback, observability.
6. Run G6 release readiness.
7. Obtain G7 explicit human approval.
8. Stage rollout.
9. Run G8 production verification.
10. Record release and update current state.
