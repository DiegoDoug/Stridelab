# Architecture Change

1. State the architectural problem and constraints.
2. Resolve affected bounded contexts/platform/services.
3. Produce options and tradeoffs.
4. Run architecture reviewer.
5. Run D04 security/privacy review when boundaries/data are affected.
6. Run D05 reliability/cost-operability input as applicable.
7. Obtain explicit human approval for the architecture decision.
8. Record ADR.
9. Implement incrementally with rollback/migration strategy.
10. Verify dependency boundaries.
