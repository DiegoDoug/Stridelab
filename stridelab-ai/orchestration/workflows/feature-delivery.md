# Feature Delivery

1. Create work package and resolve primary Department.
2. Require D01 workflow/requirement when behavior is new or changed.
3. Run D04 policy review when protected data, identity, minors, messaging/media sharing, deletion/export, or billing identity are involved.
4. Define D02/D03 implementation handoffs.
5. Implement client/platform changes.
6. Run local specialist verification.
7. Run D05 quality/performance/reliability checks.
8. Run required cross-Department review.
9. Update durable project knowledge.
10. If releasing, continue into release flow.
