# Cross-Department Phase Gates

Gates are **conditional**: use only those relevant to the task, except mandatory gates triggered by risk.

- **G0 Authority & Context**
- **G1 Product / Workflow**
- **G2 Architecture / Contracts**
- **G3 Security / Privacy / Compliance**
- **G4 Implementation Integrity**
- **G5 Quality / Performance / Reliability**
- **G6 Release Readiness**
- **G7 Human Approval**
- **G8 Production Verification**

A failed mandatory gate blocks completion.
