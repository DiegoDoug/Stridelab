# Work Package Contract

Every orchestrated material task should resolve:

```yaml
work_id:
title:
request:
primary_department:
primary_agent:
collaborating_departments:
required_skills:
upstream_artifacts:
affected_bounded_contexts:
affected_apps_platform_services:
risk_flags:
required_gates:
human_approval_required:
expected_outputs:
verification_plan:
status:
```

The work package is orchestration metadata, not a replacement for product/engineering artifacts.
