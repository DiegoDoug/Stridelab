# /prepare-release-candidate

## Primary owner
Department 05 / `release-engineer`, coordinated by root orchestrator.

## Required inputs
- candidate scope;
- D02/D03 implementation evidence;
- D04 security/privacy/compliance disposition;
- D05 quality/performance/reliability evidence;
- migration/backup/rollback plan;
- observability readiness.

Output a release candidate package and G6 disposition. Production promotion still requires G7 explicit human approval.
