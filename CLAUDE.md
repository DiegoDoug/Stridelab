# StrideLab AI Operating Instructions

Before changing StrideLab:

1. Read `stridelab-ai/project-memory/current-state/`.
2. Read `stridelab-ai/orchestration/ORCHESTRATOR.md`.
3. Classify the request and resolve the owning Department from `stridelab-ai/registry/`.
4. Load the assigned agent and its required skills.
5. Read `stridelab-ai/application-map/` before modifying application code.
6. Read relevant requirements, decisions, ADRs, security/compliance constraints, and upstream artifacts.
7. Make the smallest coherent change that satisfies the approved contract.
8. Run required verification and cross-department gates.
9. Record durable decisions, verification evidence, and current-state changes.

Do not convert proposals into approved decisions without explicit approval. Do not weaken security/privacy boundaries to make implementation easier.
